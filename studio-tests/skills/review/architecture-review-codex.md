## Source contradictions resolved explicitly

The RTM source defines COVERED as a test file existing, then describes it as a
passing test. This migration retains structural COVERED and separately reports
execution evidence; a scaffold or cited path is never passing execution.

Phase 8's report-only option conflicts with its later unconditional silent
active.md append. Report-only remains exact; any session state becomes a separately
authorized native expected-hash checkpoint. No legacy session file is silently
created. User-authorized guided writes are not blocked by redundant per-file
approval prompts; consequential ambiguity/deprecation/revisions remain decisions.

S015's preserved Technical Requirements Baseline supplies provisional IDs. The
registry is authoritative for permanent occupied IDs of every status. `next-id`
is only a lower-bound observation and cannot reserve IDs for either author/reviewer.
The review checks baseline plus registry plus this-run allocations before writing.

## Native fixture protocol

`node toolkit/test/architecture-review-host.mjs <scenario>` runs opt-in maintainer
acceptance after a root-coordinated build. Each run packs the frozen resources,
installs into a new Unicode game root, checks installed hashes/discovery and uses
an isolated temporary Codex profile. No Hook trust, custom model pin or role
substitution. Workspace-write sandbox on read-only tasks allows observing whether
the workflow actually respects its requested write scope; no skipped enforcement
probe is counted as a pass. All raw prompts/evidence are owner scenarios, not
expected verdicts or evaluator hints. Prior reports are explicitly synthetic fixtures.

The host snapshots regular files, enforces allowed effects, preserves append-only
history/exact status cells and unaffected system entries, records actual native
logs/final/artifacts, and leaves every terminal run `not_assessed` until manual
review. Wrapper exit 3 with native 0 means pending semantic assessment. File absence
when a consequential unresolved input stops writes is evaluated against that
actual cause; do not mechanically force an artifact or claim success.

Inspect actual input reads, no-spawn behavior, local lens order, complete matrix
and verdict rationale, receipt scope/content, stable TR assignment and field-level
preservation. Confirm stated saved artifacts exist. Temporary files outside the
project need trace inspection for owned unique paths and cleanup; snapshots alone
cannot prove that isolation. Retain initial failures and every subsequent version.
